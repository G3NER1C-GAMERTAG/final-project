The CIA Framework

Core Framework

Data is a valuable asset. The primary goal of cybersecurity is to maintain three critical properties - collectively known as the CIA Triad - for all data, all the time.

Confidentiality

Data is not revealed

Protection against UNAUTHORIZEDD ACCESS. Only those with proper permission should ever be able to read or view the data.

Think of it as a locked diary - only the owner (or those granted access) can read it.

Example: Edward Snowden's 2013 leak of classified NSA government data is a landmark example of a Confidentiality breach.

Integrity

Data is intact - not modified or corrupted

Protection against unauthorized modification. Data must remain accurate and trustworthy from the moment it is created until it is accessed.

If someone changes your grade in the grade book without permission, that's an Integrity breach.

Example: The Stuxnet worm secretly altered code on Iranian centrifuge macines, causing them to spin too fact and physically break - a classic Integrity attack.

Availability

Data is accessible to allowed users

Protection against denial of service. Authorized users must be able to access data and systems whenever they legitimately need them

A website that is always down, or an account that stays locked, fails the availability test.

Example: The Mirai Botnet used 145,000+ infected cameras and devices to flood security journalist Brian Krebs' website with traffic, crashing it for four days - a textbook DDoS / Availability breach.

Security Formula: Prevention + (Detection + Response) = Protection. Every cybersecurity technique fits into at least one of these three elements, and every element maps back to the CIA Triad.
