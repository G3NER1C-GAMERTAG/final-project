Password Storage

Password Hashing & Salting

Passwords should never be stored as plain text. The most common safe storage method is hashing - a one-way mathematical transformation.

🔢 What is Hashing?

One Way Conversion

Software that automatically tests every possible character combination until the correct password is found. Thorough but slow for complex passwords.

🌈 Rainbow Tables

Attack Method

Uses a large database of common words, names, and character substitutions (like p@ssw0rd) to rapidly guess passwords. Much faster than pure brute force.

🧂 Salting

Defense Method

Tests one weak password against many accounts. Avoids account lockouts because each account only receives one incorrect attempt.

🖥️ Pass-the-Hash

Advanced Attack

Uses stolen username/password pairs from a known breach to attack other sites. Effective because 54% of people reuse passwords from across accounts.

Where are passwords stored?
On Windows: in the SAM registry hive.
On Linux: in /etc/shadow (root access only).
The older /etc/passwd file is world-readable and not safe for passwords.
